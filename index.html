Telemaco Control por BLE

Robot de tracción diferencial que se maneja desde un joystick en el navegador mediante Bluetooth Low Energy. El ESP32 funciona como servidor BLE y recibe las coordenadas del joystick en formato X:0.50,Y:-0.80.

  • Mezcla diferencial: izquierda = Y - X, derecha = Y + X.
  • Zona muerta de 0.05 para evitar movimientos fantasma.
  • Seguridad: si pasan más de 250 ms sin recibir comandos, o si se pierde la conexión, los motores se detienen.

Ver el joystick web (hermes-ble-joystick)

Minos Autónomo

Robot que sigue una mano usando sensores infrarrojos y avanza en línea recta gracias a un controlador PID basado en encoders.

EstadoCuándoQué hace
AvanzarAmbos sensores frontales detectan la manoVa recto corrigiendo con PID
Girar izquierdaSolo el sensor izquierdoArco a la izquierda
Girar derechaSolo el sensor derechoArco a la derecha
DetenidoSin manoMotores apagados
  • Antirrebote de 60 ms para ignorar luz infrarroja ambiental.
  • El PID compara los ticks de ambos encoders para mantener ruedas sincronizadas.

Raiden Mando Bluetooth

Robot de dos motores controlado con un mando Bluetooth usando la librería Bluepad32. Tiene cuatro modos de manejo que se cambian al vuelo con L1 + cruceta.

ModoDescripción
ArcadeUna palanca para avanzar y otra para girar
TanqueUna palanca por cada motor
Arcade stutterAl avanzar alterna izquierda y derecha
Tanque stutterLos motores avanzan y paran de forma alternada
  • Con R2 se desactiva el stutter para tener tracción total.
  • Los motores se detienen si el mando se desconecta.

Tecnología en común

  • ESP32 como cerebro de cada robot.
  • Puente H con PWM para controlar la velocidad y el sentido de los motores.
  • Tres formas de control: BLE desde el navegador, mando Bluetooth y sensores autónomos.
  • Seguridad por software: los motores se paran ante pérdida de conexión.
